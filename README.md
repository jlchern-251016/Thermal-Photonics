## 📖 Overview

**Thermal Photonics** presents the first unified framework for thermal system design, bridging conductive heat transfer (diffusionics) and radiative heat transfer (thermal photonics) through the novel **Mode-Path Matrix (MPM)** methodology.

> 🎯 **The Central Innovation:** The **Mode-Path Matrix** does for thermal engineering what circuit theory did for electrical engineering and aberration theory did for optical design—it provides a systematic methodology that transforms intuition-based practice into a formal discipline.

> 💡 **Core Insight:** Heat is not waste—it is information waiting to be engineered. But engineering requires methodology, not intuition.
